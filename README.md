# Solunit

Landing corporativa de **Solunit — Soluciones Únicas Tecnológicas**.

## Desarrollo

```bash
pnpm install
pnpm dev
```

```bash
pnpm build
pnpm preview
```

## Contenido

El copy vive en `src/data/content.ts`. Las reglas de marca para agentes están en `AGENTS.md`.
